# هاكاثون الطلاب القادة من أجل الدمج — نظام فرق حي

## الإعداد

- Python 3.10+
- تثبيت الحزم: `pip install -r requirements.txt`
- على Windows PowerShell:
  `$env:HACKATHON_HOST_PIN="رمز_سري_قوي"`
- على macOS/Linux:
  `export HACKATHON_HOST_PIN="رمز_سري_قوي"`
- التشغيل من داخل المجلد: `uvicorn server:app --host 0.0.0.0 --port 8000`
- فتح الموقع: `http://localhost:8000`

## تشغيل مباشر لثمانية فرق

1. يفتح المنظم الموقع، يختار «المنظم» ويكتب الرمز السري لإنشاء الغرفة.
2. يفتح الشاشة المشتركة برابط «شاشة العرض»؛ يظهر رمز الغرفة ورابط الانضمام ورمز QR.
3. ينضم **فريق واحد لكل جهاز** باستخدام الاسم ورمز الغرفة.
4. يتحكم المنظم في الانتقال بين الأسئلة؛ مهلة السؤال 30 ثانية، وإجابة واحدة لكل فريق.
5. بعد كل سؤال تُعرض الإجابة الصحيحة وترتيب الفرق مباشرة.
6. نقاط كل إجابة صحيحة 100 نقطة دون نقاط سرعة.
7. يستطيع المنظم تنزيل النتائج CSV.

## النشر

الموقع لا يصبح متاحاً عبر الإنترنت إلا عند نشر الخادم على خدمة تستضيف Python وتدعم WebSocket وHTTPS (مثل Render أو Railway أو خادم خاص). اضبط `HACKATHON_HOST_PIN` كمتغير بيئة قبل النشر. يجب تشغيل **نسخة خادم واحدة** لأن حالة الغرف تُحفظ في `rooms.json` المحلي، وليست موزعة بين نسخ الخادم. احتفِظ بنسخة احتياطية من ملف الغرف والنتائج قبل إيقاف الخادم.

الأصوات المحلية لا تحتاج إلى ملفات خارجية؛ تُنتج باستخدام Web Audio API بعد ضغط المستخدم على زر تمكين الأصوات. ولا يتضمن المشروع إرسال بيانات إلى أطراف ثالثة.

### حدود هذه النسخة

- لا تتضمن تسجيل دخول مؤسسياً أو حماية متقدمة من هجمات الخدمة العامة، لذلك يوصى باستخدام رابط غير معلن وغرفة محدودة.
- دخول المنظم محمي برمز سري، والتوكن الخاص بالمنظم يحتفظ به المتصفح؛ لا تشاركه مع الفرق.
- إذا أعدت تشغيل الخادم أثناء سؤال، تعاد الغرفة إلى نتائج السؤال دون احتساب إجابات غير مكتملة؛ يرجى تجنب إعادة التشغيل أثناء الجولة.
- لا تحتوي على تحكيم ابتكار مفتوح أو حسابات فردية؛ هذه النسخة مخصصة للمسابقة الجماعية الحية بأسئلة اختيار من متعدد.
